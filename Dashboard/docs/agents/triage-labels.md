# Triage Labels

Engineering skills speak in canonical triage roles. This file maps those roles to the actual label strings used in this repo's GitHub Issues.

| Canonical role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer needs to evaluate this issue. |
| `needs-info` | `needs-info` | Waiting on reporter or stakeholder clarification. |
| `ready-for-agent` | `ready-for-agent` | Fully specified and ready for an agent to implement. |
| `ready-for-human` | `ready-for-human` | Requires human implementation, judgment, access, or review. |
| `wontfix` | `wontfix` | Will not be actioned. |

Category labels use `bug` for broken behavior and `enhancement` for new capability or improvement.

If GitHub labels are renamed later, update only the `GitHub label` column and keep the canonical role names stable for skills.
